# BicodeMel

BicodeMel is a Discord music bot built with Node.js, featuring music playback and an interactive Discord Activity for real-time playback and queue management.

The project uses YouTube and Spotify as music sources and provides an interactive interface directly within Discord.

## Installation and Configuration

### Requirements

- Node.js 22 or later
- npm
- A Discord application created in the [Discord Developer Portal](https://discord.com/developers/applications)

### 1. Clone the repository

```bash
git clone https://github.com/dotlk/Discord-MusicBot.git
cd Discord-MusicBot
```

### 2. Install dependencies

```bash
npm install
cd activity
npm install
cd ..
```

### 3. Configure environment variables

Create a `.env` file in the project root:

```env
DISCORD_TOKEN=your_bot_token
CLIENT_ID=your_application_id
CLIENT_SECRET=your_application_client_secret

ACTIVITY_PORT=3001
```

### 4. Build the Activity

```bash
cd activity
npm run build
cd ..
```

This generates the production frontend in `activity/dist`, which is served automatically by the bot.

### 5. Register Discord commands

```bash
node deploy-commands.js
```

## Execution

Start the bot from the project root:

```bash
node index.js
```

The startup process automatically:

- Connects the bot to Discord.
- Initializes the Activity HTTP server.
- Starts the Cloudflare Quick Tunnel.
- Serves the production Activity frontend.

### Important: Discord Activity URL Mapping

**After starting the bot, copy the public HTTPS URL generated by Cloudflare from the console and configure it in the Activity URL Mapping in the Discord Developer Portal.**

The Activity will not load correctly until this mapping is configured with the current tunnel URL.

**Note:** Cloudflare Quick Tunnels generate a new URL each time they restart. You must update the URL Mapping whenever the tunnel URL changes.

To update the Activity frontend after making changes, run `npm run build` again inside the `activity` directory before restarting the bot.
